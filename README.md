## 三种"防DDoS"到底差在哪

免费基础防护跟着云主机的公网 IP 走，攻击流量超过阈值就直接黑洞，IP 被封。第三方代理商写的一篇实操帖里提到，阈值大约在 5G，封禁时长 30 分钟到 2.5 小时，这个数字官方帮助文档并没有公布，只能当参考。真正的麻烦是免费防护藏不住源站 IP，攻击者查到 IP 就能一直打，你只能换 EIP 临时救站。

高防 IP 走的是另一条路。官方帮助文档的描述是"通过将网站流量牵引至高防节点进行清洗，过滤恶意攻击流量，并将正常访问流量转发回源站"。流量先到清洗节点，攻击被丢掉，干净的部分回源。源站 IP 全程不暴露，被打的也是清洗节点的 IP。

高防服务器／高防 VPS 是第三种。防御能力绑在机器所在的机房线路上，机器开通就带防护，不用改 DNS、不用配 CNAME。代价是防护和这台机器是连在一起的，想换防护档位就得换机器，不像高防 IP 那样能原地升级。

雨云的产品形态属于第三种。从命名和配置看，它卖的是整台带清洗能力的云主机或独立服务器，不是单独的牵引服务。这意味着你不用处理 CNAME 切换那套流程，但也意味着你没法只买"一个防护入口"而不换现有服务器。

## 免费防护为什么一定会黑洞

阈值的具体数值各家不同，机制是一样的：免费防护的清洗带宽是按整个可用区共享的，攻击量一旦突破单 IP 的保底额度，系统只能把这个 IP 封掉，保住其他用户。

黑洞期间你的网站对所有人都是不可达的，攻击者达到了目的。攻击者算过账：用几千块钱的流量打你 2 小时，你的客服、订单、游戏服全部停摆，损失远超防御费用。这就是小站被打一次之后往往会被反复打的原因。

高防的价值不在于"完全挡住"，而在于把攻击成本转移到清洗节点上。清洗节点的带宽是按 T 级规划的，你打不穿它，攻击者的钱就白花了。

## 买了高防不等于网站就安全了

这是前排文章基本不提的一条。某云厂商的高防帮助文档里，常见问题第一条就是：

> **我刚购买了实例，网站是不是就受保护了？**
> 不是。购买实例只是第一步。在控制台完成**添加网站**配置，然后将您域名的 DNS 解析指向 DDoS 高防提供的 CNAME 地址。只有在 DNS 切换生效后，您的网站流量才会经过高防，从而获得保护。

也就是说，你付完钱的那一刻，流量还在往源站跑。必须建好网站配置、把 DNS 指过去，防护才真正开始工作。

切换顺序同样有讲究。文档里给的是三步，并且明确警告"如果转发配置未生效就执行业务切换，将可能导致业务中断"：

1. **放行回源 IP**：在源站服务器的防火墙或安全组里，把高防的回源 IP 段加白名单。不做这一步，高防转发回来的流量会被源站当成攻击拦掉，网站直接打不开。
2. **本地验证**：改自己电脑的 hosts 文件，把域名指向高防节点，确认转发配置按预期工作，再动 DNS。
3. **切换 DNS**：本地验证通过后再改解析记录，指向高防 CNAME。

顺序反了，就是从"被攻击"直接变成"自己把自己打挂"。这一步做错的案例比想象中多。

雨云这类整机带防御的产品没有 CNAME 这个环节，开通即用。但如果你以后想在不换机器的情况下换防护，就得回到高防 IP 这条路，那套流程一样躲不掉。

## 只在帮助文档里写的限制

如果你决定走高防 IP，下面这些数字会直接影响你买几档。以下以某云厂商的高防帮助文档为例，各家具体数值不同，但限制的**类型**是共通的，采购前值得逐条问一遍。

- **一个域名最多关联 8 个高防实例**，且只能关联同一功能套餐下的实例。
- **所有接入实例的自定义端口总数不超过 10 个**，含不同协议下的端口。业务端口多的（比如游戏服要开一堆 UDP 端口）会先撞上这条。
- **源站域名最多 10 个**，泛域名和精确域名同时存在时精确域名优先；填一级域名不防护二级域名。
- **回源重试默认 3 次**，超过次数仍不可达就进入静默，不再转发和探测，静默结束后才重新拉起。
- **自定义 Header 最多 5 个**，且不能占用 `X-Forwarded-For`、`ssl_client_ja3_fingerprinting_md5` 这些默认字段。
- **Cookie 下发默认开启**，用于 CC 防护和客户端区分。接入后如果用户登录闪退、会话丢失，可以关掉下发，但文档同时警告"关闭此功能会影响部分 CC 防护策略的效果"。掉线和挨打的取舍，得自己权衡。
- **全量日志分析是增值服务，需单独开通**。你以为买完就能查攻击日志，实际还得再付一笔。
- **HTTP2 监听打开后，回源仍然是 HTTP/1.1**，单连接最大并发流只有 4。

这些条文有一个共同点：都不在销售页上，只有掏钱之后才会碰到。做选型时把这几条抄下来问客服，比对比参数表有用。

## 按场景选防御档

**先看你被打到过多少 G。** 没超过 10G 的，20G／100G 档随便挑，雨云 32 元那台 20G 的深圳机器就够。被 50G 以上打过的，别在 20G 档上省钱，清洗带宽被打穿的后果是整个 IP 被封，省下的几十块钱一次都赔不回来。

**带宽方向和防御是两件事。** 雨云多数高防机型的上传只有 10～15M，下载给到 100M。如果你的业务是向外发大流量（视频、下载站、直播推流），防御再高也会先被带宽卡死。反过来，普通网站、游戏服的上行需求很小，这种配置正合适。

**游戏服优先看主频。** Minecraft 的 TPS 对单核性能极其敏感，9950X 的 150G 防御和 14900K 的 10G 防御摆在一起，如果同时被打和掉帧，选 9950X 更稳。

**四层业务不用折腾端口转发。** 整机自带防御的机型，游戏服的 UDP 端口、APP 的 TCP 端口直接开就行，不需要像高防 IP 那样另外配对外端口和源站端口的映射规则。业务端口多、又不想被"总数不超过 10 个"卡住的，这一条比省几十块钱重要。

**需要隐藏源站 IP 就别选高防服务器。** 整机带防御的方案，你的真实 IP 依然是那个 IP，只是机房在前面挡了一层。想彻底不暴露源站，只能走高防 IP 加回源白名单那条路。

## 常见问题

**防御 30G 够不够用？**
取决于你被打到多少。中小网站、个人博客、几十人在线的游戏服，30G 以下基本够用。电商、棋牌、支付类业务是重点目标，攻击动辄上百 G，得按 100G 以上规划。判断依据应该是你实际收到过的攻击峰值，不是"感觉应该够"。

**高防 IP 和高防服务器有什么区别？**
高防 IP 是把域名解析指到清洗节点，源站不用动，防护可以随时升级，但要走 CNAME 切换流程，且受端口数、域名数这些配额限制。高防服务器／高防 VPS 是整台机器就在带防护的机房里，开通即用，不用改 DNS，但防护和机器绑定，换档位就得换机器，源站 IP 也不会被隐藏。

**接入之后用户登录一直掉线怎么办？**
先看是不是 Cookie 下发导致的。高防默认开启 Cookie 下发用于区分客户端，部分有状态业务（多级子域、老式 Session 机制）会因为 Cookie 被改写而会话丢失。可以在控制台关闭下发状态，代价是部分 CC 防护策略失效。关闭后仍然掉线，再排查回源 IP 白名单和 TLS 版本配置。

**攻击日志要另外买吗？**
基础的高防实例通常只提供攻击流量概览，全量日志分析属于增值服务，需要单独开通并付费。如果你的业务需要按攻击源做取证或对账，这一笔预算要提前算进去。

**雨云的高防需要改 DNS 吗？**
按它的产品形态不需要。你买的是一台已经处在高防机房内的云主机或独立服务器，开通后直接部署业务即可，不涉及把域名解析指向第三方清洗节点。具体以开通后的官方说明为准。
